## Metrics library note (open question carried to Unit 1)

- Phase 1/2 (gateway-mvc-executor-java8, gateway-mvc-java21) use `io.prometheus:simpleclient*` directly.
- Phase 3 (gateway-mvc-blocking-spring5, gateway-mvc-webclient, gateway-webflux) use Micrometer
  (`io.micrometer:micrometer-registry-prometheus`) per docs/decisions/phase3-metrics-contract.md.
- `io.prometheus:simpleclient` 0.16.0 (Phase 1/2's exact pinned version) has NOT been tested against
  Spring Boot 4.1.0 / Java 21 in this Unit 0 pass — Spike A/B only proved the web/MVC/VT skeleton, not
  the metrics library. Micrometer 1.17.0 (resolved above) is Spring Boot 4.1.0's own managed version
  and is confirmed compatible (Spike C built and ran with it).
- Because Phase 4 needs the *same* metrics library across M1/M2/M3 (Unit 0 design brief §4 "공통 Runtime"
  requires identical Micrometer version), and only Micrometer was actually proven under Boot 4.1.0 in
  this pass, Micrometer is the reuse candidate for Unit 1 — NOT io.prometheus:simpleclient. This is a
  deviation from Phase 2's own metrics library choice and must be decided explicitly in Unit 1, not
  assumed here.
